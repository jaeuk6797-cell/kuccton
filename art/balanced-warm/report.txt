Appearance
Balanced is an explicit selectable tone. Existing Warm/default appearances are
preserved. Balanced uses botanical green stems (#719A78), leaves (#8AB99A),
and darker mineral greens (#64856D), with a cream/champagne environment and
soft lavender reflections. Petal recoloring retains the input hue, moderates
saturation, and raises lightness. Seven emotion hues and four representative
sound hues remain distinct; measured petal hue error is 0 degrees in each case.
Sound tree crowns stay green while retaining variation from the input color.
Blender stems/leaves use green shader uniforms and a soft satin surface.
Blender petal bodies use each flower's mapped source hue. Baked vertex colors
supply facet luminance, with pearl restricted to bright facets at at most 22%.
All seven Blender category body colors match the procedural palette exactly.

Performance scope
The preview reports animation-frame interval and CPU time around rendering;
these are not direct GPU timings. Samples can be browser-throttled or affected
by outliers. Focused samples still depend on browser focus,
display refresh, and concurrent workload; no controlled GPU/FPS claim is made.
The implementation adds no geometry, postprocessing passes, or render targets.

Final-source timing observations (milliseconds; Warm -> Balanced):
Garden, 180 frames each: frame mean 17.59 -> 16.76, p95 25.0 -> 16.8;
render CPU mean 3.38 -> 2.59, p95 5.4 -> 3.4.
Peonies, 114 / 84 frames: frame mean 33.84 -> 30.36;
render CPU mean 5.27 -> 6.58. The sampling windows are incomplete.
Rotated, 49 / 100 frames: frame mean 25.17 -> 19.17;
render CPU mean 7.92 -> 5.16. Incomplete windows and long outliers limit use.
Dense 50, 36 / 22 frames: frame mean 37.96 -> 34.09;
render CPU mean 20.53 -> 25.81. These short windows cannot establish parity.
Portrait 50, 180 / 8 frames: frame mean 16.67 -> 43.76;
render CPU mean 6.73 -> 23.97. The Balanced window is too short for comparison.
The later live tone-switch check collected 180 frames for each tone: frame mean
16.62 -> 16.76 (both p95 16.8), render CPU mean 2.93 -> 2.94 (both p95 3.7).
These observations establish no causal speedup or regression. Structural cost
parity (same geometry, passes, and measured draw workload) is verified; equal
frame performance on a controlled device has not been established.
